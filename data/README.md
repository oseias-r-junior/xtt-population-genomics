# Data

No data are included in this repository. Data and derived results will be released with the associated publication.

To run the workflow on your own data, place the inputs in the project root with this layout:

```
raw_genomes/<genome>.fasta        # genome assemblies
metadata/genome_clades_master.tsv # genome identifier and clade assignment (see metadata/README.md)
```

Third-party tool databases (DefenseFinder models, PADLOC database, geNomad database, VirSorter2 database, PHASTEST) are installed following each tool's own documentation. They are not distributed here.

Genome accessions will be listed here upon publication.
